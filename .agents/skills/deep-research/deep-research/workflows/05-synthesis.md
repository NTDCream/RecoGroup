# Synthesis Workflow

<required_reading>
**Đọc trước khi execute:**
- prompts/report-writing.md (report structure và style)
- templates/report.md (output format)
</required_reading>

<purpose>
Compile all accumulated learnings into a comprehensive final report.
</purpose>

<inputs>
| Input | Description |
|-------|-------------|
| `{topic}` | Original research topic |
| `{clarification_file}` | Path to 01-CLARIFICATION.md |
| `{learnings_file}` | Path to LEARNINGS.md |
| `{sources_file}` | Path to SOURCES.md |
| `{output_type}` | "report" or "answer" |
| `{output_file}` | REPORT.md or ANSWER.md |
</inputs>

<process>
## Step 1: Read All Inputs

1. Read `{clarification_file}` for context
2. Read `{learnings_file}` for all learnings
3. Read `{sources_file}` for all URLs

## Step 2: Analyze & Organize

Group learnings by theme:
- Identify major categories/sections
- Cluster related learnings
- Note patterns and connections
- Identify gaps or contradictions

## Step 3: Generate Report Structure

Plan report sections:
1. Executive Summary
2. Section 1: {theme}
3. Section 2: {theme}
4. Section 3: {theme}
5. Key Insights
6. Conclusions
7. Sources

## Step 4: Write Report

Using `prompts/report-writing.md`, generate comprehensive report.

If `{output_type} == "answer"`:
- Write concise answer instead
- Focus on direct response to query
- Skip detailed structure

---

## Step 5: Write to Output File

Write to `{output_file}`:

```markdown
# Research Report: {topic}

> **Date:** {date}
> **Parameters:** breadth={breadth}, depth={depth}
> **Total Sources:** {count}

---

## Executive Summary

{2-3 paragraph overview of key findings, main conclusions, and recommendations}

---

## Table of Contents

1. [Introduction](#introduction)
2. [{Section 1}](#{slug})
3. [{Section 2}](#{slug})
4. [{Section 3}](#{slug})
5. [Key Insights](#key-insights)
6. [Conclusions](#conclusions)
7. [Sources](#sources)

---

## Introduction

{Context about the research topic, why it matters, scope of this report}

---

## {Section 1 Title}

{Detailed content organized from learnings}

### {Subsection}
{More detailed content}

[Source: {url}]

---

## {Section 2 Title}

{Detailed content}

---

## {Section 3 Title}

{Detailed content}

---

## Key Insights

Based on this research, the following key insights emerged:

1. **{Insight 1}:** {brief explanation}
2. **{Insight 2}:** {brief explanation}
3. **{Insight 3}:** {brief explanation}
4. **{Insight 4}:** {brief explanation}
5. **{Insight 5}:** {brief explanation}

---

## Conclusions

{Synthesis of findings}

{Recommendations if applicable}

{Limitations of this research}

---

## Future Research Directions

Areas that warrant further investigation:

1. {direction_1}
2. {direction_2}
3. {direction_3}

---

## Sources

{Numbered list of all URLs}

1. {url_1}
2. {url_2}
3. {url_3}
...

---

*Generated by Deep Research Skill*
*{timestamp}*
```
</process>

<answer_mode>
If `{output_type} == "answer"`:

```markdown
# Answer: {topic}

## Direct Answer

{Concise, direct answer to the question based on research}

## Supporting Evidence

{Key facts that support the answer}

## Sources

{Top 5-10 most relevant sources}
```
</answer_mode>

<quality_checklist>
Before finalizing, verify:

- [ ] All learnings incorporated (not just some)
- [ ] Proper structure with headings
- [ ] Executive summary captures essence
- [ ] Inline citations where relevant
- [ ] Sources section complete
- [ ] No major gaps or contradictions unaddressed
- [ ] Conclusions are supported by findings
- [ ] Length appropriate (3+ pages for report)
</quality_checklist>
