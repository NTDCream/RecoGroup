# Report Writing Prompt

> **Source:** Adapted from [dzhng/deep-research](https://github.com/dzhng/deep-research/blob/main/src/deep-research.ts) - `writeFinalReport()`

---

## Purpose

Compile all accumulated learnings into a comprehensive, well-organized research report.

---

## Prompt Template

```
Given the following prompt from the user, write a final report on the topic using the learnings from research.

<original_query>
{query}
</original_query>

<clarification_context>
{clarification_qa}
</clarification_context>

<learnings>
{all_learnings}
</learnings>

## Instructions

1. Make the report as detailed as possible, aim for 3 or more pages
2. Include ALL the learnings from research
3. Organize information in a clear, readable format
4. Use proper markdown headings and structure
5. Include an executive summary at the beginning
6. End with conclusions and key takeaways
7. Cite sources inline where relevant

## Executive Summary
```

---

## Parameters

| Parameter | Description |
|-----------|-------------|
| `{query}` | Original user query |
| `{clarification_qa}` | Follow-up Q&A if any |
| `{all_learnings}` | Accumulated learnings from all depth levels |

---

## Report Structure Guidelines

### Executive Summary
- 2-3 paragraphs
- Key findings only
- No details, no citations
- Reader should understand main takeaways

### Detailed Findings
- Organized by logical sections
- Each section has clear heading
- Include all learnings
- Cite sources inline: `[Source: URL]` or footnotes

### Key Insights
- Bullet points
- Actionable, memorable
- 3-7 items

### Conclusions
- Synthesis, not repetition
- Recommendations if applicable
- Limitations of research

### Sources
- Numbered list
- All URLs visited
- Organized if possible (by type/section)

## Key Principles

1. **Comprehensive** - Include ALL learnings, don't skip
2. **Organized** - Logical structure, clear headings
3. **Cited** - Sources for verification
4. **Actionable** - Conclusions should help decisions
5. **Self-contained** - Reader doesn't need external context
